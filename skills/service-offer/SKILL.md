# Oferta de servicios

Convierte «sé hacer muchas cosas» en una oferta clara que un cliente entienda en un minuto: qué
problema resuelves, para quién, en qué paquetes y cuánto cuesta. Para consultores, asesores y
profesionales independientes.

## Cuándo usarla

- «Soy consultora de recursos humanos y no sé cómo presentar lo que hago.»
- «¿Cuánto cobro por un diagnóstico de procesos?»
- «Quiero tres paquetes: básico, intermedio y completo.»

## Qué necesito de ti

- Qué sabes hacer y los resultados que has logrado (con cifras si las tienes).
- A qué tipo de cliente quieres atender: sector, tamaño, ubicación, quién decide la compra.
- Cuántas horas al mes puedes dedicar y cuánto necesitas ganar al mes.
- Lo que cobra tu competencia, si lo sabes.
- Si falta algo importante, haz como máximo 3 preguntas cortas y sigue con supuestos marcados como
  «Supuesto:».

## Cómo trabajo

1. Problema: lo escribo en palabras del cliente, no en jerga del consultor.
2. Cliente ideal: sector, tamaño, quién decide, cuándo suele tener el problema.
3. Resultado: qué cambia para el cliente y cómo se mide.
4. Paquetes: armo tres niveles (entrada, principal, completo) con alcance, entregables, duración y
   lo que NO incluye. El de entrada es pequeño y fácil de aprobar.
5. Precio: calculo tu tarifa mínima por hora = (ingreso mensual deseado + gastos del negocio) ÷
   horas facturables al mes (uso 60 % de tus horas disponibles como facturables). Luego precio
   cada paquete por horas estimadas y lo contrasto con el valor que genera al cliente.
6. Precios en quetzales sin IVA y con IVA (12 %; verificar en portal.sat.gob.gt, revisado el 9 de
   noviembre de 2026). Si eres pequeño contribuyente o tienes otro régimen, confirma con tu
   contador.
7. Prueba: casos, cifras, testimonios con permiso, certificaciones o una garantía razonable.
8. Cierro con la frase de presentación en una línea y el siguiente paso para el cliente.

## Lo que te entrego

```
OFERTA DE SERVICIOS — [tu nombre o marca]

Problema que resuelvo: ...
Cliente ideal: ...         Quién decide: ...
Resultado que logra: ...   Cómo se mide: ...

| Paquete | Para quién | Incluye | No incluye | Duración | Precio sin IVA (Q) | Con IVA (Q) |
|---|---|---|---|---|---|---|
| Entrada | | | | | | |
| Principal | | | | | | |
| Completo | | | | | | |

Tarifa mínima por hora: Q __ (cálculo: ...)
Prueba: [caso, cifra, testimonio, certificación]
Presentación en una línea: «Ayudo a [cliente] a [resultado] en [plazo] sin [dolor].»
Siguiente paso para el cliente: ...
Supuestos: ...
```

## Reglas

- Nunca prometo resultados que no dependen de ti; la garantía debe ser cumplible.
- Testimonios y casos solo con permiso del cliente; si no lo hay, se anonimizan.
- No invento cifras de logros: si no hay datos, el caso se cuenta sin números.
- Impuestos y régimen fiscal: verificar con la SAT o tu contador; no es asesoría tributaria.
- Para la propuesta a un cliente concreto, usa `proposal-builder`; para tu perfil en LinkedIn,
  `cv-builder`.

## Ejemplo

**Pedido:** «Soy consultor en seguridad industrial en Escuintla. Quiero ganar Q 18,000 al mes,
tengo 120 horas disponibles y Q 2,000 de gastos.»
**Entrega (resumen):** Tarifa mínima Q 278 por hora (Q 20,000 ÷ 72 h facturables). Paquetes:
Diagnóstico de riesgos en planta (2 días, Q 4,500 sin IVA), Programa de seguridad y capacitación
(6 semanas, Q 22,000) y Acompañamiento anual (Q 6,500 al mes). Prueba: 3 plantas sin accidentes
incapacitantes en el último año, a confirmar con permiso de los clientes.
