# Estrategia en una página

Ordena una estrategia de área, región o negocio en una página que todo el equipo entienda y que se
pueda revisar cada mes. Para directores y gerentes que necesitan alinear a su gente rápido.

## Cuándo usarla

- «Tengo que presentar la estrategia comercial 2027 de mi región.»
- «Mi equipo no sabe cuáles son las prioridades.»
- «Tengo muchas ideas sueltas; conviértelas en un plan con indicadores.»

## Qué necesito de ti

- El objetivo principal y el horizonte (trimestre, semestre, año).
- La situación actual: dónde están hoy, con 2 o 3 cifras si las tienes.
- Las ideas o iniciativas que ya tienes y el equipo disponible.
- Si falta algo importante, haz como máximo 3 preguntas cortas y sigue con supuestos marcados como
  «Supuesto:».

## Cómo trabajo

1. Si hay datos de clientes, metas individuales o cifras confidenciales, propongo `data-shield`.
2. Reescribo el objetivo para que sea medible: qué, cuánto y para cuándo.
3. Elijo como máximo 3 prioridades. Lo que no entra queda en «Lo que NO haremos», a la vista.
4. Para cada prioridad defino 2 o 3 acciones con responsable (cargo, no nombre) y fecha.
5. A cada prioridad le pongo un indicador de resultado y uno de avance, con línea base y meta.
6. Señalo los recursos que se necesitan y los riesgos que podrían frenar el plan.
7. Propongo el ritmo de revisión: qué se mira cada semana y qué cada mes.

## Lo que te entrego

```
ESTRATEGIA [área] — [periodo]

Objetivo: [qué, cuánto, para cuándo]
Punto de partida: [2–3 cifras de hoy]

| Prioridad | Acciones | Responsable | Fecha | Indicador de avance | Indicador de resultado (base → meta) |
|---|---|---|---|---|---|
| 1. | a) b) | | | | |
| 2. | | | | | |
| 3. | | | | | |

Lo que NO haremos este periodo: ...
Recursos necesarios: ...
Riesgos y cómo los cuidamos: ...
Revisión: semanal [qué] / mensual [qué]
Supuestos por confirmar: ...
```

## Reglas

- Máximo 3 prioridades: más de 3 deja de ser estrategia.
- Todo indicador tiene línea base, meta y fuente del dato. Si no hay línea base, la primera acción
  es medirla.
- En banca y empresas reguladas, metas por cliente, tasas y cartera real se trabajan anonimizadas y
  solo en la IA aprobada por la institución.
- No invento cifras del mercado; si hacen falta, sugiero `market-brief` o `source-researcher`.
- La IA propone; tú y tu comité deciden.
- Para comunicarla al equipo después, usa `team-update`.

## Ejemplo

**Pedido:** «Soy gerente regional de una cooperativa en Huehuetenango. Queremos crecer en
créditos para mujeres emprendedoras el próximo año.»
**Entrega (resumen):** Objetivo: pasar de 1,200 a 1,800 créditos activos de ese segmento a
diciembre 2027. Prioridades: 1) alianzas con 10 asociaciones de mercados, 2) proceso de
aprobación en 5 días hábiles, 3) educación financiera mensual. NO haremos: abrir agencias nuevas.
Indicadores con línea base marcada como «Supuesto: por confirmar con el área de créditos».
