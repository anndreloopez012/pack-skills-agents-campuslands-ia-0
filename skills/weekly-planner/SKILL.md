# Organiza mi semana

Convierte una lista larga de pendientes en un plan por día que sí cabe en tu tiempo. Para quien
siente que la semana se le va en apagar fuegos.

## Cuándo usarla

- «Tengo estas 20 tareas y 3 reuniones. Arma mi semana.»
- «Me cayó un encargo urgente, reacomoda lo que queda del jueves y viernes.»
- «Organiza mi lunes.»

## Qué necesito de ti

- Tu lista de pendientes, como la tengas (con fechas límite si las sabes).
- Tus reuniones y compromisos fijos (día y hora), incluidos los personales que no se mueven.
- Tu horario de trabajo y a qué hora rindes mejor.
- A quién puedes delegar.
- Si falta algo importante, hago como máximo 3 preguntas cortas y sigo con supuestos marcados
  como «Supuesto:» (por ejemplo: jornada de 8:00 a 17:00 con almuerzo de 13:00 a 14:00).

## Cómo trabajo

1. Calculo el tiempo de cada tarea; si no lo sé, lo estimo y lo marco. Divido lo que pase de
   3 horas en partes.
2. Clasifico cada tarea:
   - **Hacer ya:** urgente e importante (vence pronto y tiene consecuencias).
   - **Agendar:** importante, no urgente (proyectos, planificación, aprendizaje).
   - **Delegar:** urgente pero otra persona puede hacerlo.
   - **Soltar o posponer:** ni urgente ni importante.
3. Resto del tiempo disponible: reuniones, traslados y un 20 % libre para imprevistos.
4. Pongo lo difícil en tus horas de mejor energía y agrupo tareas parecidas (llamadas, correos).
5. Si no cabe todo, lo digo claro y propongo qué mover, negociar o soltar.
6. Marco las 3 prioridades de la semana: si solo logras eso, la semana valió.

## Lo que te entrego

```
MI SEMANA — del [lunes] al [viernes] de [mes]
Horas disponibles: __  | Horas de tareas: __  | Margen para imprevistos: __

3 PRIORIDADES: 1) ... 2) ... 3) ...

| Tarea | Grupo | Tiempo | Vence | Día y hora |
|---|---|---|---|---|

AGENDA
| Hora | Lunes | Martes | Miércoles | Jueves | Viernes |
|---|---|---|---|---|---|
| 8:00–10:00 | | | | | |
| 10:00–12:00 | | | | | |
| 12:00–13:00 | | | | | |
| 14:00–16:00 | | | | | |
| 16:00–17:00 | | | | | |

DELEGAR: [tarea → persona, mensaje sugerido]
NO CABE: [tarea → propuesta: mover a / negociar fecha / soltar]
```

## Reglas

- Respeto los compromisos fijos y personales; no lleno cada minuto.
- Siempre dejo margen: una agenda al 100 % se cae el martes.
- Los asuetos y feriados de Guatemala cuentan: si hay uno en la semana, lo descuento y lo aviso
  (verifica el calendario oficial del año).
- No muevo tus citas en el calendario: te doy el plan y tú lo pasas a tu agenda.
- Si una tarea viene de una reunión, puedes traer la minuta de `meeting-kit`; si hay muchos
  correos por contestar, ordénalos antes con `inbox-triage`.

## Ejemplo

**Pedido:** «Soy contador en un despacho de Cobán. Esta semana: cierre de 4 clientes, declaración
mensual de IVA de 6 clientes, reunión con un cliente nuevo el martes 10:00, capacitación el jueves
toda la tarde, y quiero estudiar Excel 1 hora.»
**Entrega (resumen):** 3 prioridades: declaraciones de IVA antes de su vencimiento (verificar fecha
en el portal de la SAT), cierres de los 2 clientes más grandes, preparar la reunión del martes. IVA
en las mañanas de lunes y miércoles, cierres repartidos, Excel el viernes temprano. No cabe: el
cierre del cuarto cliente; propone mover al lunes siguiente avisando al cliente con un mensaje listo.
