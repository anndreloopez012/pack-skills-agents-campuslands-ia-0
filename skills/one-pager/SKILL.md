# Resumen de una página

Convierte un informe, contrato, ley, presentación o acta larga en una sola página que se lee en
tres minutos. Para gerentes, directores y cualquiera que deba decidir sin leerlo todo.

## Cuándo usarla

- «Resume este informe de 40 páginas para la gerencia.»
- «¿Qué cambia para nosotros con este acuerdo?»
- «Dame lo importante de este contrato antes de la reunión.»

## Qué necesito de ti

- El documento (PDF, Word o texto pegado). Si es muy largo, puedes mandarlo por partes.
- Quién lo va a leer (gerencia, junta, equipo, cliente) y para qué (informarse o decidir).
- Si falta algo importante, hago como máximo 3 preguntas cortas y sigo con supuestos marcados
  como «Supuesto:».

## Cómo trabajo

1. Si el documento trae datos personales o de clientes, te propongo usar antes `data-shield`.
2. Lo leo completo antes de resumir; si solo pude leer una parte, lo digo.
3. Identifico la idea central en una frase: de qué trata y por qué importa ahora.
4. Elijo los 5 puntos que más cambian algo para el lector (dinero, plazos, obligaciones,
   riesgos, oportunidades). Cada punto con la página o sección donde está.
5. Para cada punto escribo el impacto concreto: «qué significa para nosotros».
6. Identifico la decisión que se necesita, quién la toma y para cuándo. Si no hay decisión, lo digo.
7. Anoto lo que el documento no aclara y conviene preguntar.

## Lo que te entrego

```
RESUMEN DE UNA PÁGINA
Documento: [título, autor, fecha, n.º de páginas]   Para: [lector]   Preparado: [fecha]

EN UNA FRASE: ...

5 PUNTOS CLAVE
| # | Punto | Impacto para nosotros | Dónde está (pág./sección) |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |
| 5 | | | |

CIFRAS QUE IMPORTAN: [monto en Q, porcentaje, fecha] — fuente: pág. __

RIESGOS SI NO SE ACTÚA: ...

DECISIÓN QUE SE NECESITA: [qué] — decide: [quién] — antes de: [fecha]
(o «No requiere decisión; es informativo»)

LO QUE EL DOCUMENTO NO ACLARA: ...
```

## Reglas

- Una página de verdad: si no cabe, recorto; no agrego anexos.
- Cada cifra y cada afirmación salen del documento, con su página. No agrego datos de fuera sin
  decirlo.
- No opino sobre lo que el documento no dice; si me pides opinión, va aparte y marcada.
- En contratos o normas, no doy asesoría legal: señalo los puntos para revisar con un abogado.
- Lenguaje llano: si el documento usa siglas o términos técnicos, los explico en paréntesis.
- Si el resumen va a un comité para decidir entre opciones, el siguiente paso es `decision-memo`
  si está instalada; si va a una exposición, `doc-to-presentation`.

## Ejemplo

**Pedido:** «Resume este informe de auditoría interna de 40 páginas para el gerente general de
una cooperativa en Quetzaltenango.»
**Entrega (resumen):** En una frase: tres agencias no cumplen el procedimiento de arqueo diario.
Cinco puntos: arqueos incompletos (pág. 12), diferencias de caja por Q 18,400 en el semestre
(pág. 15), firmas faltantes en 30 % de expedientes (pág. 21), sistema sin bitácora de cambios
(pág. 27), capacitación pendiente (pág. 33). Decisión: aprobar el plan de corrección antes del 30
de noviembre. No aclara: quién es responsable del seguimiento.
