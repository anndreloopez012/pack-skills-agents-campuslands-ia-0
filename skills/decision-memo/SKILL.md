# Memo de decisión

Convierte un tema complejo en un memo de dos páginas como máximo que un comité pueda leer y decidir
en una sola sesión. Para gerentes y directores que presentan a comités de crédito, de riesgo,
de dirección o juntas directivas.

## Cuándo usarla

- «Tengo que llevar esto al comité el jueves.»
- «Compara estas tres opciones y dime cuál recomendarías.»
- «La gerencia necesita decidir si abrimos la agencia en Cobán.»

## Qué necesito de ti

- La decisión que hay que tomar, en una frase, y quién la toma.
- Las opciones que ya existen (o el problema, si aún no hay opciones).
- Datos disponibles: costos, plazos, impacto, restricciones, fecha límite para decidir.
- Si falta algo importante, haz como máximo 3 preguntas cortas y sigue con supuestos marcados como
  «Supuesto:».

## Cómo trabajo

1. Si hay nombres de clientes, cifras de cartera, tasas o datos de personas, propongo `data-shield`
   antes de seguir.
2. Escribo la decisión pedida en una línea, con fecha límite y responsable.
3. Resumo el contexto en 5 líneas como máximo: qué pasó y por qué hay que decidir ahora.
4. Incluyo siempre la opción «no hacer nada» como base de comparación.
5. Comparo las opciones con los mismos criterios: costo, beneficio, plazo, riesgo, reversibilidad.
6. Para cada riesgo anoto probabilidad, impacto y cómo se mitiga.
7. Doy una recomendación con su porqué en tres razones y lo que haría cambiar la recomendación.
8. Cierro con los próximos pasos si se aprueba.

## Lo que te entrego

```
MEMO DE DECISIÓN
Para: [comité]   De: [área]   Fecha: [ ]   Decidir antes de: [ ]

1. Decisión que se pide (una línea)
2. Contexto (máx. 5 líneas)
3. Opciones
| Criterio | Opción 0: no hacer nada | Opción A | Opción B |
|---|---|---|---|
| Costo (Q) | | | |
| Beneficio esperado | | | |
| Plazo | | | |
| Riesgo principal | | | |
| ¿Se puede revertir? | | | |
4. Riesgos
| Riesgo | Probabilidad (B/M/A) | Impacto (B/M/A) | Mitigación |
|---|---|---|---|
5. Recomendación: Opción __ porque 1) ... 2) ... 3) ...
   Cambiaría la recomendación si: ...
6. Próximos pasos si se aprueba (qué, quién, cuándo)
Supuestos y datos por confirmar: ...
```

## Reglas

- En banca, los datos de clientes, tasas reales y depositantes son confidenciales: el memo se arma
  con estructura y cifras anonimizadas o agregadas. Usa solo la IA aprobada por tu institución.
- Toda cifra lleva su origen («según presupuesto 2026», «estimado del área»). Nada inventado.
- Si una opción depende de una norma (Superintendencia de Bancos, SAT, Código de Trabajo), indico
  verificarla en la fuente oficial con la fecha de revisión; nunca cito artículos de memoria.
- Recomendación honesta: si los datos no alcanzan para recomendar, lo digo y pido lo que falta.
- La IA prepara; el comité decide.
- Si el insumo es un informe largo, primero resúmelo con `one-pager`.

## Ejemplo

**Pedido:** «El comité debe decidir si renovamos el sistema de turnos de 12 agencias o lo
cambiamos. Tengo dos cotizaciones: Q 180,000 y Q 245,000.»
**Entrega (resumen):** Memo con Opción 0 (seguir con el actual, fallas 3 veces al mes), A
(Q 180,000, 4 meses, sin soporte local) y B (Q 245,000, 2 meses, soporte en Guatemala).
Recomienda B por plazo y soporte; cambiaría a A si el presupuesto 2027 no se aprueba antes de
enero. Supuesto marcado: costo de cada falla, por confirmar con Operaciones.
